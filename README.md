# Abaynesh Farm & Cafe — Reference-led redesign

## Files
- `index.html` — complete homepage structure and copy
- `style.css` — responsive visual design
- `script.js` — navigation, automatic hero slideshow and reveal effects

## Run locally
Keep all three files in the same folder and open `index.html` in your browser.

## Before publishing
The Unsplash photographs are visual placeholders, not confirmed photographs of Abaynesh. Replace them with real farm, cattle, cafe, milk and juice photographs when available. Keep each image's subject and crop in mind; the layout uses wide landscape images for the hero and full-bleed sections.

No menu prices, opening hours, phone number or unconfirmed business claims have been added.
